# Online Judge

A production-oriented Online Judge built from scratch in Modern C++ on Linux.

## Goals

This project is designed to learn and demonstrate:

- Linux Systems Programming
- Operating Systems
- Process Management
- Inter-Process Communication
- Backend Engineering
- Docker
- Sandboxing
- Databases
- REST APIs
- Distributed Systems

The objective is not only to build an Online Judge but also to understand the engineering principles behind production systems.

## Current Status

- Project initialized
- CMake build system configured
- Initial project architecture established
- ProcessRunner interface created
